Shot Log

Connect your log

Your shots and photos are saved in your private GitHub repo, so they sync between your phone and computer. Each device needs a key once.
  1. Open GitHub → new fine-grained token.
  2. Name it Shot Log and set Expiration to the longest option.
  3. Under Repository access pick Only select repositories and choose your data repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it, and paste it below.
The key stays on this device only. Use the same key on your phone and computer, or make one per device.
